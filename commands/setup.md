description: Install or check what Agentic Cut needs on this computer (once per computer, and after updates)
---

Use the agentic-cut skill. Run its ready check (`AC doctor`). If anything says FIX, help the user install it (offer
to run the printed command), then run `AC setup` and wait for `READY`. Explain that the first setup downloads the
render browser and the on-device speech model, about 5 to 10 minutes, and that nothing leaves their computer.
When it's ready, offer to set their brand (accent colour, font, caption style, handle) in one message, and invite them
to share the first video they want edited.
